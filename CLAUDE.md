# Project: periodic3d — interactive 3D periodic table

## Goal
A fun, public, static web app hosted on GitHub Pages. Must look polished,
load fast, and work on phones.

## Hard rules
- Vanilla JavaScript ES modules + Three.js + Vite. No React, no other frameworks.
- Static only: no backend, no API keys, no analytics, no external API calls at runtime.
- NEVER hard-code element data. All facts come from public/data/*.json, which are
  generated by scripts/*.py from the files in scripts/raw/. Never hand-edit them.
- If a value is missing in the data, show "unknown". Never guess.
- One responsibility per module; follow the folder structure below.
- Tiles are CSS3DRenderer objects (crisp HTML text). Only the Bohr atom uses WebGL,
  in its own small canvas inside the panel.
- Cap renderer pixel ratio at 2. Pause animation when the tab is hidden.
- Support prefers-reduced-motion and touch input.
- vite.config.js base must stay '/periodic3d/' (must equal the repo name).
- Load JSON with fetch(`${import.meta.env.BASE_URL}data/...`) so paths work on GitHub Pages.

## Folder structure
```
src/main.js              wires modules together (selection, state -> view)
src/data/loader.js       fetch + cache JSON
src/scene/setup.js       renderer, camera, controls, resize, idle rotation, camera flights
src/scene/layouts.js     table / sphere / helix / grid target positions
src/scene/tiles.js       118 tiles: create, move, colour, select, tap picking
src/scene/atom.js        Bohr model (WebGL) for the selected element
src/ui/panel.js          detail panel
src/ui/spectrum.js       emission spectrum canvas
src/ui/legend.js         category chips / heatmap scale / states legend
src/ui/controls.js       search box + toolbar
src/ui/colors.js         category colours, heatmap ramp, states, wavelength -> RGB
src/ui/toast.js          status messages
src/ui/theme.css         all styles
src/features/tour.js     song tour (audio + timeline sync)
src/features/keyboard.js arrow-key navigation and shortcuts
src/utils/state.js       app state, URL hash, localStorage prefs
src/utils/tween.js       tiny tween runner
src/utils/device.js      reduced motion, low-detail, WebGL checks
src/utils/format.js      number/text formatting ("unknown" for missing)
scripts/build_data.py    PubChem CSV + Periodic-Table-JSON -> elements.json
scripts/build_spectra.py NIST lines -> spectra.json
scripts/build_timeline.py song order -> timeline.json
scripts/validate_data.py sanity checks (runs in CI before every deploy)
```

## Style
- Dark theme: background #0b0f17, text #e6e9ef, one accent #3ad1e6.
- Font: Inter (self-hosted via @fontsource-variable/inter). Detail panel is HTML/CSS, not 3D text.
- Bohr models and spectra are labelled "simplified".

## Working rules
- Work on ONE step at a time. Don't add features I didn't ask for.
- After each change, run `npm run build` and fix all errors before stopping.
- If you touch data scripts, run `npm run data` and make sure the validator passes.
- Keep functions small with clear names and short comments.
- Summarise what you changed and how I should test it.
